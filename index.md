# Tcar Clips

Canal independente de carros no YouTube: preços da Tabela FIPE, curiosidades e diferenciais dos modelos que fizeram história no Brasil.

**Canal no YouTube:** [youtube.com/@Tcar_clips](https://www.youtube.com/@Tcar_clips)

## Motor Shorts

O Motor Shorts é uma ferramenta interna, usada exclusivamente pelo dono do canal, para gerar e publicar vídeos curtos no canal @Tcar_clips. A publicação é feita pela **API de Dados do YouTube** (Serviços de API do YouTube), apenas com permissão de envio de vídeos para o próprio canal.
