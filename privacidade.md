# Política de Privacidade — Motor Shorts

Última atualização: 16 de outubro de 2026

O Motor Shorts é uma ferramenta interna do canal Tcar Clips (youtube.com/@Tcar_clips). Ela é usada apenas pelo próprio dono do canal para gerar vídeos curtos e publicá-los no canal @Tcar_clips. O aplicativo não é oferecido ao público e não tem outros usuários.

## Dados acessados

O Motor Shorts usa os Serviços de API do YouTube com uma única permissão: enviar vídeos para o canal autorizado (escopo youtube.upload). A ferramenta não lê, coleta nem armazena dados de espectadores, comentários, inscritos, contatos ou qualquer outra informação pessoal de terceiros.

## Armazenamento e compartilhamento

O único dado guardado é o token de autorização do próprio dono do canal, mantido como segredo criptografado no GitHub e usado apenas para publicar os vídeos. Nenhum dado é vendido, compartilhado ou transferido a terceiros.

## Serviços do Google e do YouTube

Ao usar esta ferramenta, aplicam-se os Termos de Serviço do YouTube (https://www.youtube.com/t/terms) e a Política de Privacidade do Google (https://policies.google.com/privacy).

## Revogar o acesso

O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions. Ao revogar, o token deixa de funcionar imediatamente.
